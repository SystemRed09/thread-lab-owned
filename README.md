## What is in this repository

| Project | Type |
|---|---|
| `Threads.Core` | Class library — `File`, `Reader`, `Writer`, `Status`, `FileController` |
| `Threads.ReadWrite` | WinForms — Reader form, Writer form, self-test |
| `Threads.Race` | Console — the token race |
| `Threads.Deadlock` | Console — two jobs, two files |

Open `Lab-Threads.sln`. `Threads.Core` is a class library with no `Main`; to run one
of the other three, right-click it and choose **Set as Startup Project**.
